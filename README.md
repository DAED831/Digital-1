# Digital-1
Almacenamiento de información respecto al proceso de creación de el proyecto de la asignatura. 

La creación de los diagramas se hizo mediante código "mermaid" con asistencia de Gemini by Google para la sintaxis pero de diseño propio, se crean dos archivos; uno para visibilidad del código y el otro para visibilidad de la gráfica. Pará mejorar visibilidad se paso la misma estructura a un código HTML.
